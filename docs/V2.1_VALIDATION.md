# JBrowser 2.1.0 static validation report

## Checks performed in the authoring environment

- Confirmed the source package contains the GeckoView MainActivity, extension manager and bookmark store.
- Updated Gradle configuration to AGP 9.1.1, compile SDK 37 and Gradle 9.3.1 workflow.
- Configured ABI splits for ARM64, ARMv7, x86 and x86_64; universal APK generation is disabled.
- Enabled release R8 code shrinking and resource shrinking.
- Enabled compressed native-library APK packaging to prioritize download size.
- Updated workflow to inspect each APK's native library paths and verify exactly one ABI per APK.
- Updated application version to 2.1.0 / version code 8.
- Parsed Android manifest XML and checked ZIP structure after packaging.

## Not verified

- No full Gradle/Android build was run in this authoring environment because Android SDK and Gradle are unavailable here.
- Actual APK size is unknown until GitHub Actions builds the artifacts.
- R8 compatibility with GeckoView and the extension APIs has not yet been runtime-tested.
- No real Android TV hardware test was performed.
- Installed storage size, startup time and RAM usage have not been measured.

## Release caution

The release variant is signed with a temporary GitHub runner debug key. Use a persistent private keystore stored in GitHub Actions secrets for production releases and repeatable app updates.
