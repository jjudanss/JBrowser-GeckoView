## Important limits

- This workspace does not have Android SDK / Gradle available for a full APK build. GitHub Actions is the first real compile test.
- GeckoView's native engine is bundled with the app. Per-ABI APK splits reduce downloaded bytes, but compressed native libraries are extracted on install, so installed storage is much larger than the APK. The code changes target runtime responsiveness and memory, not a dramatic engine-size reduction.
- uBlock Origin is downloaded separately on demand from Mozilla Add-ons. GeckoView WebExtensions support is not identical to full Firefox; extension compatibility must be tested. Chrome extensions are not supported.
- No extension can guarantee that every YouTube advertisement or anti-adblock mechanism will be defeated.
