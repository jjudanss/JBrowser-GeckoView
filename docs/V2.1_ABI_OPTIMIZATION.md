# JBrowser 2.1.0 ABI packaging — historical notes

JBrowser 2.1.0 introduced ABI-specific GeckoView APKs instead of one universal package. Actual successful GitHub Actions output reported approximately:

- ARM64: 88 MB
- ARMv7: 85 MB
- x86_64: 93 MB

The attempted x86 build did not produce a usable native GeckoView binary and was removed from later workflows. JBrowser 2.2.0 continues with ARMv7, ARM64 and x86_64 only.

The maintainer later reported that the 85 MB ARMv7 download occupied approximately 280 MB after installation. This is consistent with compressed `.so` libraries being extracted during installation. ABI splits reduce download size; they do not make GeckoView's native engine itself smaller.
