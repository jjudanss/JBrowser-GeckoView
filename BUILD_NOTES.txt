No universal APK is generated. Native libraries are compressed to reduce download size and extracted at installation, increasing installed storage usage. Release builds enable R8 and resource shrinking. GeckoView's native engine remains the primary size factor and is not meaningfully reduced by R8.

GitHub Actions builds optimized signed release APKs with:
  gradle --no-daemon clean assembleRelease

The workflow checks APK contents to ensure exactly one ABI is packaged in each output. Actual APK sizes will be printed in the workflow log after the first successful build.

The release is signed with a temporary runner debug key for testing. A persistent private signing key should be configured through GitHub Actions secrets before public distribution.

A full Android build and real-device tests have not been run in this authoring environment.
