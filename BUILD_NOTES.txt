JBrowser 2.2.0 build notes

Browser engine: Mozilla GeckoView 160.0.20261116130455
Android minimum: 8.0 / API 26
Compile SDK: Android 17 Preview / API 37.0
Target SDK: 36
Java: 17
Android Gradle Plugin: 9.1.1
Gradle: 9.3.1

APK outputs:
- armeabi-v7a
- arm64-v8a
- x86_64

No 32-bit x86 GeckoView native library is provided by the selected engine dependency, so that ABI is not built.

R8 and resource shrinking are enabled for release APKs. Native GeckoView libraries are compressed in the APK download and extracted by Android during installation. This reduces download size, but not installed storage footprint.

uBlock Origin is not bundled. The app offers an on-demand installation from the official Mozilla Add-ons XPI URL. GeckoView validates the Mozilla signature and asks the user to approve extension permissions. GeckoView's extension API compatibility is not identical to full Firefox; test the installed extension on target devices.

The app caps tabs at three, lowers priority for inactive Gecko sessions, suspends inactive-tab media and limits per-frame pointer event dispatch. These target runtime memory and responsiveness, not native engine size.

The Android SDK / Gradle build must be run through GitHub Actions. This source bundle has not been compiled against an Android SDK in the authoring environment.
